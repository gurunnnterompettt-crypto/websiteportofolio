## Isi Folder

## Cara Menjalankan
1. Ekstrak file ZIP.
2. Buka folder hasil ekstrak.
3. Klik dua kali `index.html`.
4. Website akan terbuka di browser.

Tidak membutuhkan XAMPP/server untuk versi ini. Internet hanya diperlukan jika ingin memuat font Google Fonts.
